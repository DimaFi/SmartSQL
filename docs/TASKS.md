## Сквозная работа

- **T23 — интерфейс и доступность:** полный проход всех частей UI, выравнивание/отступы/высоты, таблицы/вкладки/дерево/инспектор, согласованная плотность и плавные переходы без скачков/мерцания/потери состояния. Прямое замечание и скриншот пользователя 15 октября фиксируют оставшуюся доводку; порядок функциональных задач сохраняется. Русский сначала, клавиатура/фокус, масштаб, контраст и доступные сообщения. После каждого значимого сценария и отдельная итоговая UI-приёмка.
- **T24 — диплом и поставка:** self-contained Windows x64 EXE/ZIP, manifest/SHA и отдельный запуск на D: уже проверены; [скрипты и инструкция](DELIVERY.md). Начат Inno Setup-сценарий; компиляция/установка/обновление/удаление ещё не проверены (ISCC отсутствует). Синтетический сценарий практики и материалы продолжаются; дедлайна нет.
- **T25 — качество и хранение:** D:, отдельные тестовые базы, чистые коммиты без данных/весов/секретов, обновление плана/матрицы/передачи. После каждого закрытого этапа.

К каждому реализуемому срезу назначаются отдельные владельцы файлов. Сборки/тесты и Git ведёт основной агент. Готовый код с ещё не проверенным вручную UI не закрывает T04. Завершённые задачи сохраняются в истории; ограничения и незакрытые пункты остаются видимыми.
