## Сквозная работа

- **T23 — интерфейс и доступность:** тёплые пользовательские референсы, общий стиль, русский сначала, клавиатура/фокус, масштаб и доступные сообщения. После каждого значимого сценария.
- **T24 — диплом и поставка:** синтетический сценарий практики, документация/демонстрация, воспроизводимая сборка, запуск/обновление/восстановление. Проверять по ходу этапов; календарного дедлайна нет.
- **T25 — качество и хранение:** D:, отдельные тестовые базы, чистые коммиты без данных/весов/секретов, обновление плана/матрицы/передачи. После каждого закрытого этапа.

К каждому реализуемому срезу назначаются отдельные владельцы файлов. Сборки/тесты и Git ведёт основной агент. Готовый код с ещё не проверенным вручную UI не закрывает T04. Завершённые задачи сохраняются в истории; ограничения и незакрытые пункты остаются видимыми.
