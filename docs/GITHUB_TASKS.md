# Задачи SmartSQL в GitHub

## Текущий срез 16 октября 2026: завершение T11

Серая/светлая темы, закреплённая кнопка рядом с режимом и нативная подсветка уже реализованы и частично проверены на экране в предыдущем срезе. Текущий срез исправляет завершение SQL-вкладок: очистка продолжается после ошибки отмены/освобождения, принятые операции дренируются до release, первый сбой сохраняется; повторное завершение не повторяет release. Предупреждение об ошибке завершения больше не затирается сообщением об успешном отключении. Пока открыт нативный выбор SQL-файла, вкладка/подключение/приложение явно требуют завершить или отменить этот диалог вместо ожидания неотменяемого picker. Подробнее: [READ_ONLY_SQL.md](READ_ONLY_SQL.md).

Debug: 0 предупреждений/ошибок; все **593 теста** (Domain 1 / Application 118 / Infrastructure 435 / Desktop 39), включая **55 реальных PostgreSQL-фактов**, прошли без пропусков. Добавлены три SQLite- и два PostgreSQL-теста независимых SQL-сеансов, а также детерминированная проверка очистки после throwing cancellation callback: отмена/закрытие первого не портит результаты и последующие запросы второго. Независимое ревью UI cleanup/guards выполнено. Автотесты не выдаются за приёмку интерфейса.

Новая экранная приёмка не выполнена: node_repl/computer-use дважды завершился при инициализации ошибкой `failed to write kernel assets: ... path not found (os error 3)`, в том числе после reset. Это отказ инструмента, не доказанный дефект приложения. По-прежнему открыты PostgreSQL UI, несколько SQL-вкладок и закрытие во время работы, .sql-диалоги/полное значение, IME/DPI/Narrator и полный T23. [Подготовка T12](NATIVE_INSPECTOR_PLAN.md) описывает следующий срез; API/провайдеры/панель ещё не реализованы, порядок T11 → T12 сохранён. Установщик не собран, ISCC отсутствует.
