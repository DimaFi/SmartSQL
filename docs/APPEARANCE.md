# Темы и управление окном

С 16 октября 2026 SmartSQL использует серую тему по умолчанию: нейтральные тёмно-серые поверхности, светлый текст и зелёные акценты. Светлая тема сохранена. Кнопка **«Тема: серая / светлая»** закреплена справа сверху, непосредственно рядом с переключателем простого/расширенного режима. Она меняет тему сразу во всех открытых представлениях; режим, подключения и данные не перезагружаются.

Выбор хранится отдельно от режима в `theme-preferences.json` внутри выбранного runtime-каталога на D:. Запись атомарна. Отсутствующая настройка означает серую тему; повреждённая/неизвестная настройка при чтении не затирается, используется серая тема с сообщением. Явное нажатие кнопки сохраняет новый выбор, в том числе позволяет заменить повреждённую настройку. Если сохранение не удалось, тема применяется только к текущему сеансу и появляется сообщение. Файл локальный и игнорируется Git.

Обе палитры используют одинаковые семантические DynamicResource-ключи: фон, поверхности, обычный/вторичный текст, ошибки/предупреждения, выделение, SQL и бренд. Цвет заполнения основной кнопки отделён от акцентного текста на серой поверхности. Цвета выделения текста отдельные; автоматические проверки требуют контраст текста не ниже 4.5:1 и выделения относительно поля не ниже 3:1. Эти проверки не заменяют полную приёмку доступности.

Главное окно явно использует полную системную рамку, без расширения содержимого в заголовок, с разрешёнными сворачиванием/разворачиванием/изменением размера. Пользователь подтвердил возвращение кнопок 15 октября. AX показывает системный заголовок и три действия; снимки computer-use могут содержать только клиентскую область, поэтому отсутствие рамки на таком снимке не является отдельным доказательством её отсутствия в Windows. Точная первоначальная причина не установлена.

Проверено на экране в Debug: серая тема, кнопка справа рядом с режимом, мгновенный переход в светлую, восстановление светлой после перезапуска и последующий запуск серой. Полный проход всех диалогов, High DPI/Narrator, minimum size и плавность всех переходов остаются T23.

Известный вопрос совместимости для отдельной проверки: DataGrid 12.0.1 разрешает Avalonia.Controls/Base 12.0.5 при Desktop/Win32/Fluent 12.0.3. Это не подтверждённая причина исходного замечания; зависимости в данном срезе не менялись.
