# Интерфейс SmartSQL

Общая светлая тема использует тёплый фон, зелёный акцент, мягкие границы и векторные иконки. Таблица занимает основную площадь. Интерфейс сначала развивается на русском: вверху — открытие, Excel, фильтр, сортировка, поиск и переключатель режима; слева — локальная база, таблицы и подключения.

- **Простой режим**: редактирование ячеек с автоматическим сохранением, новые записи, импорт XLSX, вставка из Excel, все форматы обмена, поиск, фильтры, сортировка и отмена последнего изменения ячейки.
- **Расширенный режим**: те же данные и действия, плюс сохранённые фильтры, ограниченный запрос словами и инспектор полей/типов. Переключение не сбрасывает таблицу или применённые условия.
- **Подключения PostgreSQL**: отдельный обозреватель схем и объектов, вкладки данных/структуры, поиск по всем полям и текстовая сортировка. Внешние данные на этом этапе доступны для чтения.

Заголовки локальных столбцов сортируют весь набор записей, повторное нажатие меняет направление. Номер слева означает позицию в текущем результате, а не идентификатор записи. Длинные значения PostgreSQL открываются полностью двойным щелчком, с отдельным отображением NULL и пустой строки и кнопкой копирования.

Команды организованы по назначению: **База**, **Импорт**, **Экспорт**, **Структура**. Кнопки будущих SQL/ИИ/диаграмм появятся вместе с соответствующими рабочими функциями.

## Как расширять

`Styles/Tokens.axaml` хранит палитру и размеры, `Styles/Controls.axaml` — общие классы оформления, `Styles/Icons.axaml` — нативные векторы. `Presentation/Strings.ru.axaml` содержит статические русские подписи основной оболочки. Список ключей и правила оформления находятся в `src/SmartSQL.Desktop/Presentation/README.md`.

`MainWindow.axaml` задаёт панели, `MainWindow.Presentation.cs` управляет уровнем детализации и инспектором. Обмен, подключения и работа с данными сохраняют отдельные обработчики. Новая кнопка использует существующий стиль и присоединяется к своей группе команд; бизнес-операции остаются в Application/Infrastructure.

Для английского потребуется вынести оставшиеся тексты диалогов/статусов и добавить полный словарь `Strings.en.axaml`. Текущая версия не предлагает частично переведённое переключение языка. Режим интерфейса пока выбирается на время текущего запуска.

Все профили, локальные данные и результаты проверок остаются на D:; в Git сохраняются исходники и документация.
