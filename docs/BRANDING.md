# Логотип SmartSQL

Основа — две присланные пользователем зелёные эмблемы S и горизонтальный логотип. Знак перерисован в векторе: выровнены края, увеличены просветы и убраны растровые артефакты. Узнаваемые две переплетённые ленты и зелёная палитра сохранены.

- `src/SmartSQL.Desktop/Assets/SmartSQL-mark.svg` — исходная геометрия знака на прозрачном фоне.
- `SmartSQL-logo.svg` — горизонтальная версия с названием для широких областей.
- `SmartSQL.ico` — Windows ICO с 32-bit PNG-кадрами 16, 20, 24, 32, 40, 48, 64, 128 и 256 px.
- `SmartSQL.png` — квадратная иконка 512 px. Светлая скруглённая подложка сохраняет контраст на разных панелях; внутри 16–32 px используется ровный зелёный вместо мелкого градиента.

`ApplicationIcon` в desktop csproj встраивает ICO в executable, а общий стиль Window задаёт его для главного окна и диалогов. Это обеспечивает значок executable/ярлыков и окон/панели задач. Внутри оболочки используется та же векторная геометрия зелёного цвета. Исходные пользовательские PNG не модифицируются и не требуются при запуске.

Перегенерация ICO/PNG без внешних пакетов, Windows + PowerShell 7:

```powershell
./scripts/Generate-BrandAssets.ps1
```

Скрипт читает вектор, использует System.Drawing с supersampling и записывает только версионируемые брендовые ресурсы. При изменении геометрии синхронизировать `UiIconBrand` в `Styles/Icons.axaml` и горизонтальную версию. 15 октября 2026 значок визуально проверен в заголовках собственных/файловых диалогов и на панели задач у опубликованного self-contained приложения; отдельная приёмка списка процессов Task Manager, Alt+Tab и High DPI пока не выполнена.
